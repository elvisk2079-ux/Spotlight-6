33 неправильных глаголов из нашей таблицы, разложенных на 14 групп по одному чередованию: в каждой группе глаголы меняются одинаково. Учить «семьями» легче, чем по алфавиту: запомнил одну модель — знаешь всю группу.

В каждой группе: таблица с озвучкой, карточки, три формы по переводу, диктант на слух, выбор формы, предложения, а в больших группах — короткий текст.

Все глаголы по группам

● V1 — начальная● V2 — Past Simple● V3 — третья форма

1. A – A – A — Все три формы одинаковые

Глагол совсем не меняется: V1 = V2 = V3. Обычно это короткие слова на -t или -d.

V1V2V3Перевод
put[pʊt]put[pʊt]put[pʊt]класть, ставить
set[set]set[set]set[set]ставить, накрывать
let[let]let[let]let[let]разрешать, позволять
read[riːd]read[red]read[red]читать

2. [iː] → [e] — Долгий [iː] становится кратким [e]

Долгий звук [iː] укорачивается до [e], и в конце появляется -t. V2 = V3: feel → felt, leave → left, mean → meant.

V1V2V3Перевод
feel[fiːl]felt[felt]felt[felt]чувствовать
leave[liːv]left[left]left[left]уходить, оставлять
mean[miːn]meant[ment]meant[ment]означать, значить

3. → [ɔːt] — Превращается в -ought [ɔːt]

V2 = V3 и оканчиваются на -ought [ɔːt]: think → thought. Так же меняются buy → bought, bring → brought, catch → caught.

V1V2V3Перевод
think[θɪŋk]thought[θɔːt]thought[θɔːt]думать

4. -n → -t — В конце появляется -t

V2 = V3: к глаголу просто добавляется -t. learn → learnt. Так же: build → built, send → sent.

V1V2V3Перевод
learn[lɜːn]learnt/learned[lɜːnt]learnt/learned[lɜːnt]учить, узнавать

5. -ind → -ound — -ind превращается в -ound

Звук [aɪ] меняется на [aʊ]: find → found. V2 = V3.

V1V2V3Перевод
find[faɪnd]found[faʊnd]found[faʊnd]находить

6. -ay/-ake → -aid/-ade — -ay / -ake превращается в -aid / -ade

V2 = V3, гласная становится короткой: say → said, make → made.

V1V2V3Перевод
say[seɪ]said[sed]said[sed]говорить, сказать
make[meɪk]made[meɪd]made[meɪd]делать, готовить

7. A – B – B — Вторая и третья форма одинаковые (смешанные)

Большая «смешанная» группа: V2 = V3, но у каждого глагола своё чередование — have → had, get → got, sit → sat, hold → held, tell → told, stand → stood, understand → understood.

V1V2V3Перевод
have[hæv]had[hæd]had[hæd]иметь
get[ɡet]got[ɡɒt]got[ɡɒt]получать
sit[sɪt]sat[sæt]sat[sæt]сидеть
hold[həʊld]held[held]held[held]держать
tell[tel]told[təʊld]told[təʊld]рассказывать
stand[stænd]stood[stʊd]stood[stʊd]стоять
understand[ˌʌndəˈstænd]understood[ˌʌndəˈstʊd]understood[ˌʌndəˈstʊd]понимать

8. A – B – A — Третья форма возвращается к первой

В Past Simple (V2) гласная меняется, а третья форма снова как первая: V3 = V1.

V1V2V3Перевод
run[rʌn]ran[ræn]run[rʌn]бежать, бегать
become[bɪˈkʌm]became[bɪˈkeɪm]become[bɪˈkʌm]становиться

9. i – a – u — Музыкальная тройка i – a – u

Гласная меняется по порядку: i → a → u. begin → began → begun. Так же: drink → drank → drunk, sing → sang → sung, swim → swam → swum.

V1V2V3Перевод
begin[bɪˈɡɪn]began[bɪˈɡæn]begun[bɪˈɡʌn]начинать(ся)

10. i – o – i + en — V2 с «o», V3 = V1 + en

В V2 появляется «o», а V3 похожа на V1, но с -en: write → wrote → written. Так же: drive → drove → driven, ride → rode → ridden.

V1V2V3Перевод
write[raɪt]wrote[rəʊt]written[ˈrɪtən]писать

11. -ew – -own — V2 на -ew, V3 на -own

V2 оканчивается на -ew [uː], а V3 на -own: know → knew → known. Так же: grow → grew → grown, throw → threw → thrown.

V1V2V3Перевод
know[nəʊ]knew[njuː]known[nəʊn]знать

12. – o – o + en — V2 с «o», V3 = V2 + en

В V2 появляется звук [əʊ] («o»), а V3 = V2 + -en: break → broke → broken, speak → spoke → spoken.

V1V2V3Перевод
break[breɪk]broke[brəʊk]broken[ˈbrəʊkən]ломать, разбивать
speak[spiːk]spoke[spəʊk]spoken[ˈspəʊkən]говорить (на языке)

13. V3 = V1 + (e)n — Третья форма = первая + -en

V2 у всех разная, а V3 образуется из первой формы с -n / -en: take → took → taken, give → gave → given, see → saw → seen.

V1V2V3Перевод
take[teɪk]took[tʊk]taken[ˈteɪkən]брать
give[ɡɪv]gave[ɡeɪv]given[ˈɡɪvən]давать, дарить
see[siː]saw[sɔː]seen[siːn]видеть

14. Особые — Глаголы-одиночки: учим целиком

Эти глаголы ни на кого не похожи — их просто запоминаем: be → was/were → been, do → did → done, go → went → gone, show → showed → shown.

V1V2V3Перевод
be[biː]was/were[wɒz]been[biːn]быть
do[duː]did[dɪd]done[dʌn]делать
go[ɡəʊ]went[went]gone[ɡɒn]идти, ехать
show[ʃəʊ]showed[ʃəʊd]shown[ʃəʊn]показывать
