# Spotlight 6 Grammar

Interactive grammar trainers for Spotlight 6 (grade 6) — «Чемоданчик учителя английского».

Site: https://elvisk2079-ux.github.io/Spotlight-6/

Source: `src/packs/*.js` (content), `src/s6/verbs.py` (irregular verbs by groups), `src/engine/` (shared engine).
Build (from `src/`): `python3 s6/build_s6.py` — writes the pages to the repo root.
